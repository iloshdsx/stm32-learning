## 一、一句话结论

**C 语言里，参数传递只有一种方式：传值。**

所谓"传地址 / 传指针"，也是传值 —— 只不过传的这个"值"是一个**地址**。

---

## 二、门牌号比喻（理解的关键）

把内存想成一排房子，每个变量住一间，变量名是房主名，**地址就是门牌号**。

| 传参方式 | 实际传了什么 | 比喻 |
|---|---|---|
| `swap_by_value(int a, int b)` | 抄了一份**值** | 给朋友一张你家的**照片** —— 他再怎么折腾照片，你家不会变 |
| `swap_by_pointer(int *pa, int *pb)` | 抄了一份**地址** | 给朋友一张你家的**门牌号复印件** —— 他照着地址就能找到你家、进门改东西 |

**核心那句：抄来的门牌号，依然指向同一间房。**

所以"传指针能改到调用方的变量"，真正的原因**不是**"指针不是传值"，而是：
**门牌号被抄了一份，但两份门牌号指向的是同一间房子。**

## 三、两个函数对照

```c
void swap_by_value(int a, int b)        /* a、b 是副本，改副本不影响原件 */
{
    int t = a;
    a = b;
    b = t;
}

void swap_by_pointer(int *pa, int *pb)  /* pa 是"指向 x 的指针"，*pa 才是"x 本人" */
{
    int t = *pa;
    *pa = *pb;
    *pb = t;
}
```

调用方式的区别：

```c
swap_by_value(x, y);       /* 把 x、y 的"值"抄一份过去 */
swap_by_pointer(&x, &y);   /* 把 x、y 的"地址"抄一份过去 —— & 就是"问门牌号" */
```

---

## 四、预测题答案

```c
int x = 1, y = 2;

swap_by_value(x, y);
printf("x = %d, y = %d\n", x, y);   /* x = 1, y = 2  —— 没变！ */
```

`swap_by_value` 里面换得再热闹，换的都是**抄件**，原件一动没动。

## 五、面试分水岭（重点）

> 问："C 语言参数传递有几种方式？"

| 回答 | 评价 |
|---|---|
| "传值和传地址两种" | 及格 |
| **"只有一种：传值。传指针也是传值，只是抄的是地址"** | **直接加分** |

为什么第二条更强：它说明你不是背口诀，而是**真的理解了内存模型**。

**追问预案**

| 面试官追问 | 怎么答 |
|---|---|
| 那为什么传指针就能改到外面的变量？ | 指针存的是地址；地址被复制了一份，但两份地址指向同一块内存 |
| 数组传参呢？ | 数组名会退化成指向首元素的指针，所以也是"传地址的值"；函数里改数组内容会影响调用方 |
| 想改指针本身（而不是它指向的东西）怎么办？ | 传二级指针 `int **`，或者把新指针 return 回去 |
| 什么时候用 `const` 指针？ | `const int *p` 表示"我不改你指向的内容"，用作只读入参；嵌入式里读数组、读缓冲区常用 |

## 六、嵌入式场景为什么老考这个

嵌入式面试的指针题一定落在三个场景，不是纯语法：

1. **内存** —— 栈上变量、传参副本、局部变量出了函数就失效
2. **寄存器** —— `*(volatile uint32_t *)0x4001080C = 0x2000;`
   这就是"直接按地址去改那间房"；`HAL_GPIO_WritePin` 底下干的就是这件事
3. **回调** —— 函数指针交给 HAL 库（比如串口接收完成回调），本质是"把函数的门牌号交出去，让别人回头来敲你的门"
