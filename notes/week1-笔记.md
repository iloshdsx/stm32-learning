## 一、知识点

### 1. GPIO
- 8 种模式：输入（浮空/上拉/下拉/模拟）、输出（推挽/开漏/复用推挽/复用开漏）
- 点灯三步：使能时钟 → 配置模式 → 写 ODR

### 2. 电路基础
- 欧姆定律 U = I × R
- LED 限流电阻：R = (Vcc − Vf) / I
- 上拉/下拉电阻常用 4.7k ~ 10k

- ls / cd / pwd / cp / mv / rm / mkdir
- chmod / grep / 管道 |
