## 二、踩过的坑（按顺序）

### 坑 1：Zadig 装驱动失败

- **必须"以管理员身份运行" Zadig**，普通双击会失败
- 正确结果：界面显示 `Driver Installation: SUCCESS`
- 不用管理员时不会报"权限不足"，只会静悄悄地失败 —— 这点最坑

### 坑 2：设备名字找不到 "fx2lafw"

- 教程里常写"选 `fx2lafw (generic driver for FX2 based LAs)`"
- 实际扫描出来叫 **`Saleae Logic`** —— 这就是 fx2lafw 驱动认出来的设备名，**没选错**

### 坑 3：采样率 20 kHz，抓了 50 秒却只看到 0~900 ms

核心公式（一定要背下来）：

```
采样窗口时长 = 采样数量 ÷ 采样率
```

| 采样数量 | 采样率 | 窗口 | 适合 |
|---|---|---|---|
| 1 M | 20 kHz | **50 秒** | 初期误设，等于什么都没看到 |
| 100 k | 1 MHz | 100 ms | 手按不准，太短 |
| 100 k | 100 kHz | **1 秒** | 抓 PWM 刚好 |
| 50 k | 50 kHz | 1 秒 | 同上 |
| 100 k | 20 kHz | **5 秒** | 要手动按的时候用这个 |

**"想又长又细"就得加数量，但数量加太大会报错（见坑 5）。**

### 坑 4：横轴变成 `ps`（皮秒）—— 视野缩过头了

单位阶梯（每级差 1000 倍）：

```
s 秒 → ms 毫秒 → µs 微秒 → ns 纳秒 → ps 皮秒
```

横轴出现 `+78181234 ps` 这种读数时：
- 说明你缩到了 **8 ps** 的窗口
- 而 `1 MHz` 采样 = 一个点 `1 µs` = `1 000 000 ps`
- **窗口比一个采样点还小 12 万倍** → 屏幕上只能是空的

**复位办法**：不用一格一格往回滚，**直接再点一次 `Run` 抓一次**，PulseView 会自动把视野缩回数据范围。

**判断"抓到没有"的信号**：
- 时间轴还是 `-10s ~ +20s` → **没数据**
- 时间轴变成 `0 ~ 100ms` 这种数据长度 → **抓到了**

### 坑 5：这个克隆版**一开触发器就报错**

```
Capture failed
generic/unspecified error
```

确认过的现象：同样的配置（100 k / 1 MHz / 只开 D0）
- 不设触发器 → 正常抓到
- 一旦给小旗子里的 D0 设成"下降沿" → **立刻报上面这个错**

结论：**这块克隆版固件不支持硬件触发，别用。**

**替代方案**：用"长窗口 + 手动按"——
把采样率降到 `50 kHz`（窗口 2 秒）或 `20 kHz`（窗口 5 秒），点 `Run` 之后手动做那个动作。

### 坑 6：顺手能减少报错的几招

1. **只留要用的通道**：点左边的通道名把 `D1`~`D7` 点暗 → 带宽降到 1/8
2. **采样数量别贪**：`1 M samples` 会失败，`100 k samples` 稳
3. **USB 口直插主机后面板**，别走扩展坞 / Hub / 机箱前面板
4. 出过错之后先**关软件 → 拔 USB → 重插 → 重开**，再扫一次

## 三、怎么读波形（别读反了）

| 看到的样子 | 意思 |
|---|---|
| 线**贴在通道行顶部** | 一直是**高电平**（比如 PA0 被内部上拉顶着） |
| 线**贴在通道行底部** | 一直是**低电平** |
| 一条平线，不动 | 信号没变（没按按键 / 夹错地方） |

## 四、夹子夹哪儿（硬件常识，很值钱）

**夹在"和信号同一列"的空孔里就行，原来接好的线一根都不用拆。**

原理：面包板上一列的 5 个孔，底下是**同一根铜条**，电位完全一样。
所以：

- 夹在空孔里 = 直接夹在那根线上
- 不需要拆线、不需要焊接
- 分析仪只是"旁听生"，**不参与电路**

夹错的判断：夹到 GND 那一列 → 波形永远是一条直线，怎么按都不动。

## 五、什么时候用逻辑分析仪最划算

| 信号 | 难度 | 说明 |
|---|---|---|
| **PWM / 方波**（100 Hz ~ 几 kHz） | ★ 容易 | 又慢又干净，不用触发器，抓 1 秒能看几百个周期 |
| UART 串口 | ★★ | 9600~115200 波特，可以直接解码出字符 |
| I2C / SPI | ★★★ | 这才是它的主场（看地址、看 ACK、看时序） |
| **按键抖动**（µs 级毛刺） | ★★★★ | 要 1 MHz 以上采样，还要恰好按在窗口里 —— 没有触发器最难 |

1. 插 USB（直插主机后面板）
